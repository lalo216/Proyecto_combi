# Curo

Lo que puede ser un demo chingón.

Pros:
Conexión con servidor + lógica de dibujo de rutas
Plantillas de compilación
Nombre + mascota + branding verde ligero
Mucho amor

Cons:
Falta dominio, necesarío para tener una app id en cualquier play o app store
Estrategía de lanzamiento, ¿Cómo vamos actualizar la app? ¿Qué tanto tiempo queremos de forma realista ofrecer mantenimiento? ¿Y si hicieramos otro repo para hacer el proyecto código abierto? ¿Permitir que usuarios agreguen rutas?
Tenemos una cantidad limitada de rutas/tiempo para hacer que la app ofrezca algo inovador.
